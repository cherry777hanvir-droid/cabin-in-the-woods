# 林间小屋 · Cabin in the Woods

一座可以走进去、点起壁炉、听雨的秋日森林小屋。纯前端、全程序化生成，无外部模型或贴图资源；电影感暖色写实与手工质感并重。


## 操作

| 输入 | 行为 |
| --- | --- |
| `W A S D` / 方向键 | 行走 |
| `Shift` | 加速 |
| 鼠标拖拽 | 旋转视角（第三人称环绕 / 第一人称环视） |
| 滚轮 | 第三人称拉近 / 拉远 |
| `V` | 切换第一人称室内视角（保留天气与时间状态） |
| `E` | 靠近可交互物体时互动（门、壁炉、木鸟、窗帘、古井） |
| `Esc` | 关闭手记面板 |

底部环境控制栏：春 / 夏 / 秋 / 冬、时间滑杆（白天 / 黄昏 / 夜晚 / 自动）、天气（晴 / 雨 / 雪 / 雾 / 雷暴）；右上角实时显示时间、季节与天气。

## 场景内容

- **小屋**：石基原木墙、交错木刻角、真实切出门窗、木瓦双坡屋顶、石砌烟囱、门廊/台阶/栏杆/长凳、门廊风灯、木柴堆。夜晚或阴天时窗户亮起暖光；雨雪会在窗玻璃、屋檐、窗台、柴堆等位置留下痕迹。
- **室内**：可点燃的壁炉（火焰、火星、跳动暖光）、木桌与两把椅子、藏书与木刻小鸟、扶手椅、带拼布被的床、地毯、吊灯、窗帘、壁炉上的画与烛台、窗边坐榻、香草与日常杂物。木鸟可查看一段手记，窗帘可开关。
- **森林与生态**：高大的橡树/桦树/松树、蕨类、草丛与落叶小径、一口带水面的旧石井（可查看手记）。四季共用同一地点和树骨架：春日嫩绿与花、夏日浓荫与夜间萤火虫、秋日暖金与落叶、冬日裸枝与积雪；晴天白天有鸟群，雨天萤火虫消失。
- **天气与时间**：程序化天空、日月与星空、云层、雾、雨线和雪；雷暴有闪电脉冲。时间/天气变化会同步影响天空、环境光色温、地面湿度/反射和粒子，并自动切换小屋窗灯。
- **界面**：电影感黄铜/胡桃木玻璃 HUD、环境状态卡、手记面板、加载与转场、第一人称准星、可交互提示与移动端响应式布局。

## 技术

- Vite + Three.js r186，ES modules。
- 所有纹理均由 Canvas 程序化绘制（木纹、树皮、石墙、木瓦、地面、树叶、蕨类、雨痕、火焰、烟雾等）。
- 实例化渲染季节树叶、蕨类、草、落叶、雨雪粒子；bloom + ACES tone mapping + CSS 胶片颗粒/暗角。
- 第三人称相机带遮挡回缩，第一人称限制在室内并带家具碰撞；视角切换通过淡入淡出避免穿墙。
- 共享世界约定见 `CONTRACT.md`，开发预览页在 `src/dev/`。
